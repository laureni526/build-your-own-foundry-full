# The Council

<!--

**Sequence:** Advocate → Critic → Beneficiary → Executor → Long View →
Weaver

**Job:** Take my idea once. Apply each voice skill in turn, holding each
output. When all five have spoken, apply the weaver skill to their outputs
and return its synthesis as the primary answer — with the five underlying
voices available below it if I want to see the raw disagreement.

**Never does:** Skip a voice to save time, collapse two voices into one
pass, or let the Weaver run before all five have actually spoken. If I've
only asked about one angle, don't convene the whole council — hand it to
the single voice instead.
